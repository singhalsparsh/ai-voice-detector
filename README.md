## 1. Quick Start

```bash
# 1. Install frontend dependencies
npm install

# 2. Install backend dependencies
cd backend
pip install -r requirements.txt
cd ..

# 3. (Optional) Train a model — see Section 6
cd backend
python train_model.py --data_dir ./data --output ./models/voice_classifier.pkl
cd ..

# 4. Start backend (Terminal 1)
cd backend
python main.py
# → http://localhost:8000

# 5. Start frontend (Terminal 2)
npm run dev
# → http://localhost:3000
```

### 5.2 `backend/main.py`

**Framework:** FastAPI with CORS (allow all origins)

**Feature extraction function (`extract_features`):**
- Input: audio file path
- Uses librosa to load audio at 22050 Hz, max 30 seconds
- Extracts 129 features (see Section 8 for full breakdown)
- Returns `{ features: np.ndarray, metrics: dict, duration: float }`

**Model loading (`get_model`):**
- Loads `models/voice_classifier.pkl` on first request
- Caches in `_model_cache` global for subsequent requests
- Returns `None` if file doesn't exist

**Endpoint: `POST /api/v1/detect`**
1. Validates file type (MP3/WAV/FLAC/OGG/M4A/AAC)
2. Validates size (max 25 MB)
3. Checks if model is loaded (404 if not)
4. Saves upload to temp file
5. Extracts 129 features
6. Scales with saved StandardScaler
7. Runs `model.predict()` and `model.predict_proba()`
8. Returns structured response

**Response format:**
```json
{
  "is_ai": true,
  "confidence": 94.2,
  "metrics": {
    "pitch_anomaly": 0.3421,
    "spectral_centroid": 2584.32,
    "mfcc_variance": 0.0847,
    "zero_crossing_rate": 0.0623,
    "spectral_rolloff": 3842.15,
    "spectral_bandwidth": 1823.67,
    "rms_energy": 0.0312
  },
  "filename": "sample.wav",
  "duration_seconds": 12.5,
  "model_used": "Ensemble"
}
```

### 5.3 `backend/train_model.py`

**CLI interface:**
```bash
python train_model.py --data_dir ./data --output ./models/voice_classifier.pkl
python train_model.py --data_dir ./data --output ./models/voice_classifier.pkl --no-augment
```

**Arguments:**
| Flag | Default | Description |
|------|---------|-------------|
| `--data_dir` | `./data` | Root directory with `real/` and `ai_generated/` subdirs |
| `--output` | `./models/voice_classifier.pkl` | Output path for trained model |
| `--no-augment` | `false` | Disable feature-space augmentation |

**Pipeline:**
1. Scan `data/real/` for audio files (label=0) and `data/ai_generated/` for AI audio (label=1)
2. Extract 129 features per file using `extract_features()`
3. If < 200 samples: augment by adding Gaussian noise (5% std, 2 extra copies → 3× total)
4. Fit StandardScaler on all features
5. Stratified 80/20 train/test split
6. Train each model with 5-fold stratified cross-validation
7. Pick best model by test accuracy
8. Build ensemble of top 2 models (soft voting)
9. Save `{ model, scaler, model_name, accuracy, feature_count, results }` to .pkl
10. Save metrics JSON to `models/logs/metrics_YYYYMMDD_HHMMSS.json`

**Models trained:**
| Model | Key Hyperparameters |
|-------|-------------------|
| RandomForest | n_estimators=300, min_samples_split=3 |
| GradientBoosting | n_estimators=200, max_depth=5, lr=0.1, subsample=0.8 |
| SVM-RBF | C=10, gamma="scale", probability=True |
| XGBoost (optional) | n_estimators=300, max_depth=6, lr=0.05, subsample=0.8 |
| Ensemble | Soft voting of top 2 by accuracy |

Create this directory structure in `backend/`:

├── real/
│   ├── speaker_001.wav
│   ├── interview_002.mp3

- ElevenLabs API outputs
- OpenAI TTS outputs

## 8. ML Model Details

### Feature Vector (129 dimensions)

Extracted from each audio file using librosa:

| # | Feature Group | Count | How |
|---|--------------|-------|-----|
| 1 | MFCC mean | 20 | `np.mean(librosa.feature.mfcc(...), axis=1)` |
| 2 | MFCC std | 20 | `np.std(librosa.feature.mfcc(...), axis=1)` |
| 3 | MFCC delta mean | 20 | `np.mean(librosa.feature.delta(mfccs), axis=1)` |
| 4 | MFCC delta std | 20 | `np.std(librosa.feature.delta(mfccs), axis=1)` |
| 5 | Spectral centroid | 2 | mean + std of `spectral_centroid` |
| 6 | Spectral rolloff | 2 | mean + std of `spectral_rolloff` |
| 7 | Spectral bandwidth | 2 | mean + std of `spectral_bandwidth` |
| 8 | Spectral contrast | 2 | mean + std of `spectral_contrast` |
| 9 | Spectral flatness | 2 | mean + std of `spectral_flatness` |
| 10 | ZCR | 2 | mean + std of `zero_crossing_rate` |
| 11 | RMS energy | 2 | mean + std of `rms` |
| 12 | Pitch | 2 | mean + std of fundamental frequency |
| 13 | Chroma | 24 | mean + std of 12 chroma bins |
| 14 | Onset strength | 2 | mean + std of onset envelope |
| | **Total** | **129** | |

### Audio Preprocessing

```
Input audio → librosa.load(sr=22050, duration=30, mono=True)
              ↓
         Pad if < 1 second
              ↓
         Extract 129 features → np.float32 vector
              ↓
         StandardScaler.transform()
              ↓
         model.predict() → 0 (real) or 1 (AI)
         model.predict_proba() → [P(real), P(AI)]
```

### Classifier Details

| Model | Algorithm | Key Parameters |
|-------|-----------|----------------|
| **RandomForest** | Bagging ensemble | 300 trees, unlimited depth, min_split=3 |
| **GradientBoosting** | Sequential boosting | 200 trees, depth=5, lr=0.1, subsample=0.8 |
| **SVM-RBF** | Support vector machine | RBF kernel, C=10, gamma=scale |
| **XGBoost** | Optimized gradient boosting | 300 trees, depth=6, lr=0.05 |
| **Ensemble** | Soft voting of top 2 | Weighted by probability |

### Training Strategy

1. **Data augmentation**: If < 200 samples, add Gaussian noise (5% of feature std) to create 3× more training data
2. **Feature scaling**: StandardScaler (zero mean, unit variance)
3. **Stratified split**: 80% train, 20% test, maintaining class balance
4. **Cross-validation**: 5-fold stratified CV for each model
5. **Model selection**: Best test accuracy wins
6. **Ensemble**: Soft voting of top 2 models (often outperforms individual)

## 10. Troubleshooting

| Problem | Solution |
|---------|----------|
| "Model binary not loaded" (404) | Run `python train_model.py` in backend/ to create the model file |
| "Unsupported format" (400) | Use MP3, WAV, FLAC, OGG, or M4A. Convert with `ffmpeg -i input.mkv output.wav` |
| librosa fails to load audio | Install ffmpeg: `brew install ffmpeg` (macOS) or `sudo apt install ffmpeg` (Linux) |
| Frontend can't reach backend | Ensure backend is running on port 8000. Check `curl http://localhost:8000/health` |
| Low training accuracy | Add more data (50+ per class). Ensure variety in speakers and recording quality |
| `npm run build` fails | `rm -rf node_modules package-lock.json && npm install && npm run build` |
| TypeScript errors | Run `npx tsc --noEmit` to see specific errors |
| Port 3000 already in use | Use `npm run dev -- -p 3001` for a different port |
| Port 8000 already in use | Change port in `backend/main.py`: `uvicorn.run(app, port=8001)` |
